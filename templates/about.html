About the Loan Approval Prediction Project

Course: Machine Learning • Section: 6B • B.Tech Computer Science & Engineering

🎯 Problem Statement

Commercial banks and lending institutions process thousands of loan applications annually. Assessing loan default risk manually is time-consuming, subjective, and prone to human inconsistency. The objective of this project is to build an automated, transparent, and accurate binary classification system to predict whether a prospective applicant is "Likely Approved" or "Likely Rejected" based on verified creditworthiness, household income, and requested loan terms.

🌳 Machine Learning Algorithm: Decision Tree Classifier

We utilize scikit-learn's DecisionTreeClassifier. A decision tree creates a flowchart-like tree structure where each internal node denotes a test on an attribute (e.g., Credit History == 1), each branch represents the outcome of the test, and each leaf node holds a class label.

Why Gini Impurity?
The algorithm measures the impurity of a node using Gini Impurity:
Gini = 1 - Σ (p_i)²
At each split, the feature and threshold that maximize information gain (i.e., produce the purest child nodes) are selected.

🛡️ Ethical Machine Learning: Eliminating Bias

Responsible AI requires careful feature selection to prevent demographic discrimination:

  • Loan_ID dropped: Arbitrary identifier with zero predictive value that would only introduce spurious correlations.
  • Gender dropped: Excluded intentionally from the feature matrix to eliminate gender-based demographic bias and adhere to fair lending standards.
  • Strict Feature Isolation: The system relies strictly on 10 objective financial and risk attributes: ApplicantIncome, CoapplicantIncome, LoanAmount, Loan_Amount_Term, Credit_History, Self_Employed, Married, Education, Dependents, and Property_Area.

⚙️ Data Preprocessing & Leakage Prevention

To prevent statistical data leakage, the dataset is partitioned into an 80% training set and 20% test set before any imputation or encoding parameters are calculated:

  • Stratified Split: Preserves the ~69% to 31% target distribution across both train and test partitions.
  • Numeric Imputation: Uses median replacement to resist outliers in income and loan amounts.
  • Categorical Encoding: Uses most-frequent imputation and scikit-learn's OneHotEncoder(handle_unknown='ignore') wrapped in a ColumnTransformer inside an end-to-end Pipeline.

⚠️ Limitations & Future Work

  • Loan Term Extrapolation: Users can enter any term from 1 month to 40 years; however, the training data contains almost no short-term loans (0 under 12 months, 1 at 12 months, 83.4% at 360 months), so predictions under 12 months are extrapolations and less reliable for educational study, not bank decisions.
  • Small Sample Size: 614 rows in the original benchmark Kaggle dataset means certain combinations of categories have few observations.
  • Class Imbalance: ~69% approval rate requires monitoring recall and false positive rates rather than relying solely on raw accuracy.
  • Educational Purpose: Built strictly for educational and instructional demonstration. Real-world underwriting requires rigorous compliance with financial regulatory bodies (e.g., Fair Credit Reporting Act).
